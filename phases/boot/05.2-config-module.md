# Phase 5.2: Config Module (config.py)

## Context

RALY's Boot harness is a custom Python process that receives Telegram messages and
delegates Claude Code CLI tasks inside ephemeral Docker containers. `config.py` is the
centralized configuration module — all settings flow through it. It loads secrets from
`~/BootDrive/data/config.env`, validates them at startup, and provides typed access. If config
is invalid, the process fails loudly and immediately.

Architecture position:

```
config.env (~/BootDrive/data/config.env, chmod 600)
    ↓ loaded at startup
config.py (this file)
    ↓ provides typed config to
security.py, telegram.py, executor.py, session.py, memory.py
```

## Prerequisites

- Phase 4 complete: `~/BootDrive/data/config.env` exists with secrets populated
- No other module dependencies — config.py is a leaf dependency

## File Location

`~/BootDrive/app/boot/config.py`

## Dependencies

- `os` (stdlib)
- `pathlib` (stdlib)
- `dataclasses` (stdlib)
- `typing` (stdlib)

Zero external dependencies. This module must never import third-party packages.

## Implementation Specification

### Config Data Structure

```python
from dataclasses import dataclass, field
from pathlib import Path
from typing import Set

@dataclass(frozen=True)
class BootConfig:
    """Immutable configuration for Boot harness.

    Loaded once at startup. Frozen (immutable) to prevent runtime modification.
    Every field has a type. No optional secrets — they're all required.
    """

    # Telegram
    telegram_bot_token: str
    telegram_allowed_users: Set[int]  # Set of numeric Telegram user IDs

    # Paths
    workspace_dir: Path    # ~/BootDrive/workspace
    data_dir: Path         # ~/BootDrive/data
    log_dir: Path          # ~/BootDrive/data/logs

    # Rate limiting
    rate_limit_requests_per_minute: int = 10
    rate_limit_max_cost_per_hour: int = 100

    # Executor
    docker_memory_limit: str = "2g"
    docker_cpu_limit: str = "2"
    docker_pids_limit: int = 256
    task_timeout_seconds: int = 300  # 5 minutes
    sandbox_image: str = "boot-sandbox:latest"

    # Database
    db_path: Path = field(default=None)  # Set in __post_init__

    def __post_init__(self):
        # Workaround for frozen dataclass: set computed fields
        if self.db_path is None:
            object.__setattr__(self, 'db_path', self.data_dir / "boot.db")
```

### Config Loader

```python
def load_config(env_path: str = None) -> BootConfig:
    """Load config from env file. Fail loudly on any missing or invalid value.

    Args:
        env_path: Path to config.env. Defaults to ~/BootDrive/data/config.env

    Returns:
        Validated, immutable BootConfig

    Raises:
        SystemExit: If any required config is missing or invalid.
        Exits the process — do not catch this. A misconfigured Boot is worse
        than a stopped Boot.
    """
```

Implementation requirements:

#### Environment File Parsing
- Parse `config.env` as KEY=VALUE pairs, one per line
- Strip comments (lines starting with `#`)
- Strip inline comments
- Strip quotes around values
- Do NOT use `python-dotenv` — it's another dependency we don't need for simple KEY=VALUE

#### Validation Rules
- `TELEGRAM_BOT_TOKEN`: required, non-empty, must match pattern `\d+:[\w-]+`
- `TELEGRAM_ALLOWED_USERS`: required, comma-separated integers, at least one
- `BOOT_WORKSPACE`: required, must be an existing directory, must be absolute path
- `BOOT_DATA`: required, must be an existing directory, must be absolute path
- Rate limit values: must be positive integers
- Docker limits: must be valid Docker format strings

#### Failure Behavior
- If ANY required value is missing: print clear error message, `sys.exit(1)`
- If ANY value fails validation: print clear error message, `sys.exit(1)`
- DO NOT silently use defaults for security-critical values
- DO NOT continue with partial config
- Print which value is missing/invalid (but NOT the value itself for secrets)

#### Security
- Never log secret values (token, API keys)
- After loading, verify `config.env` file permissions are `600` — warn if not
- Verify `config.env` parent directory permissions are `700` — warn if not

### Config Singleton

```python
_config: BootConfig = None

def get_config() -> BootConfig:
    """Return the loaded config. Raises if load_config() hasn't been called."""
    if _config is None:
        raise RuntimeError("Config not loaded. Call load_config() first.")
    return _config
```

Pattern: `load_config()` called once in `main.py` at startup. All other modules call
`get_config()` to access the singleton. Config is frozen — no runtime mutations.

from pathlib import Path

def make_test_config(**overrides):
    """Create a temporary config.env with test values."""
    defaults = {
        "TELEGRAM_BOT_TOKEN": "123456789:AAFakeTokenForTesting",
        "TELEGRAM_ALLOWED_USERS": "111222333",
        "BOOT_WORKSPACE": "/tmp/test-workspace",
        "BOOT_DATA": "/tmp/test-data",

    defaults.update(overrides)

    tmp = tempfile.NamedTemporaryFile(mode='w', suffix='.env', delete=False)

    # Create required directories

    return tmp.name
